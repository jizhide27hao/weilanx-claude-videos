# 分页与叙事

暗金文献长片不讲「镜头」，讲「页」。一页是一张账页：抬头、数字、注脚各就各位，观众自己决定先看哪儿。这份文档管三件事——**口播怎么切成一页一页、每页的节拍怎么排、哪些句子不许上字幕**。

## 一、为什么按页走

同一段素材（华为 2019 · 8,588 亿 · 实体清单）做过三种剪法，差别不在画面好不好看，在**观众的阅读权**：

| 剪法 | 观众状态 | 一屏能看几件 |
|---|---|---|
| 桌面长卷（相机一路横移） | 被镜头牵着走，只能看镜头停下的那一处 | 3–4 件，靠先后出场 |
| 网点档案（弹入 + 砸下 + 硬切） | 被节奏推着走，来不及读 | 3 件，读的是「冲击」 |
| **暗金文献（交叉淡化换页）** | **自己扫，想读哪块读哪块** | **6–8 件，同时成立** |

「研发 1,213 亿 vs 净利 234 亿」这句话的力量，全在**同时看见**。所以这套风格的第一条是：**一页里所有东西同时在场**，只靠柔入先后给眼睛一个入场顺序，不给它强制路线。

## 二、口播怎么切成一页

一页 = **一个完整的论点**，通常 2–4 句口播，6–9 秒。

- ep53：90 句 → **36 页**，平均 7.4 秒／页，2.5 句／页。
- **不许按句子数均分**。一句话讲完一件事就一页（「2002 年，营收 221 亿，唯一一次下滑」独占 3.7 秒），四句话才讲完的因果就一页（「泡沫破了 → 卖电源业务 → 换回 7.5 亿美元」占了 10.9 秒）。
- 切页的判据是**论点边界**，不是时长。判完再用 `pages.mjs check` 看时长分布是否失控。

三种页长的处理：

| 页长 | 什么时候用 | 例子 |
|---|---|---|
| 3–5.5 秒（短拍页） | 只放**一个数字或一句结论**，不许再有第二件东西 | P14 221 亿、P17 海思成立、P28 1,028 天 |
| 6–9 秒（标准页） | 论点 + 一到两个证据 | 大部分页 |
| 10–13 秒（长页） | 需要**并置**才能说清：两个数字对比、三段流程、四个画面 | P27 8,914→6,368、P30 7,042→8,809、P08 五楼窗边 |

短拍页不是「偷懒」，它是节奏的呼吸孔。连续三页 8 秒之后必须插一个 3 秒的单数字页，否则观众会疲劳。

## 三、分组：36 页 = 9 组

每组 3–5 页，组内是「立论 → 证据 → 收口」，组与组之间靠**换章音效 + 抬头年份跳一格**提示。

ep53 的分组：

1. 钩子（P01–P03）：钱眼 → 十年账 → 三次生死目录
2. 起家（P04–P09）：2.1 万 → 名字 → 代理 → 引文 → 五楼 → C&C08
3. 立规矩（P10–P12）：两份文书 → IBM → 220 亿与冬天
4. 冬天与思科（P13–P16）：断崖 → 唯一负增长 → 21 项 → 撤诉
5. 出海（P17–P19）：海思 → 75% → 500 强 397
6. 终端（P20–P23）：砍贴牌 → 微博 → Mate 7 → 2 亿台
7. 断供（P24–P27）：顶点+清单 → 三样断供 → 卖荣耀 → 落差 2,546
8. 回来（P28–P31）：1,028 天 → 12:08 → 只差 105 亿 → 汽车
9. 收尾（P32–P36）：4,678 亿 → 20.6% → −37% → 命运线 → 三样东西

写口播时就按这 9 组写上注释（`# ---- 断供 ----`），后面切页和排配乐都用得上。

## 四、切点算法

```ts
export const CUTS = [
  0,            // P01
  cf(4) - 6,    // P02 ← 第 4 句开口前 6 帧
  cf(6) - 6,    // P03
  ...
];
// 第 k 页：from = k === 0 ? 0 : CUTS[k] - FADE，to = CUTS[k+1] + FADE
// 相邻页重叠 FADE = 16 帧做交叉淡化；children 拿到的 t = f - CUTS[k]
```

四条经验：

1. **提前 6 帧（0.2 秒）**。新页在上一句说完、下一句开口前就已经成形。切在开口那一帧，观众听到第一个字时画面还在溶——像字幕迟了一拍。
2. **切线必须落在句子里，不能落在句间空隙**。空隙里切，这一页会「一句都没分到」，`pages.mjs check` 会直接报错。
3. **切点写成 `cf(n) - 6`，不要烘焙字面量**。ep53 的 `film-a.tsx` 里是字面量（298、503…），因为配音已锁死；**一旦要重录口播，字面量全部作废，`cf` 表达式自动跟随**。新一期一律写表达式。
4. **用脚本生成，不要手敲 36 个数**：

```sh
# 1. 每页第一句的 cue 序号（第 1 页的 1 可以不写，脚本会丢掉）
node .workbuddy/skills/weilanx-creator-gilded-long-video/scripts/pages.mjs scaffold --cues 1,4,6,9,13,...

# 2. 贴进 film-a.tsx 后校验页长、覆盖、页数
node .../pages.mjs check <期>

# 3. 看每页分到哪几句、有没有漏句
node .../pages.mjs map <期>
```

## 五、页内节拍（`at` 三条带）

每页内部的 `at` 都从 0 起算（`t = f - 切点`），负帧时元素还没出，正好埋在淡化里。三条带：

| 帧 | 干什么 | 组件 |
|---|---|---|
| **0–40** | 立结构：年份抬头、文献引用、表头、中缝、坐标轴 | `YearHeader` `BookCite` `MiniTable` 的表头 `VLine` `HLine` `Ruler` |
| **40–150** | 填证据：数字、柱、条目，`at` 对齐那句口播开口的时刻 | `Figure` `BarsV` `KV` `Col` `Mark` |
| **150 以后** | 只留结论、印章、脚注，**不再出新元素** | `RedStamp` `RuleFade` `Note` |

两条纪律：

- **每页最后 40–60 帧必须是静场**（元素仍在，但没有新东西进来）。这段静场要和下一页的溶入重叠，观众才有「读完」的时间。ep53 的 3 秒短页也守这条：数字 40 帧内到齐，剩下 50 帧什么都不动。
- **结构必须先立**。抬头、表线、中缝在 0–40 帧就位，数据慢慢填进来，观众看到的是「一张正在被填写的账页」，而不是「东西一件件蹦出来」。空着的格子是「待填」，不是「没做完」。

## 六、同文让位

画面里已经把一句台词排成大引文时，**字幕要让位**：

```tsx
<GSub f={f} cues={CUES} y={948} skip={[17, 20, 21]} />
```

ep53 让位的是三处：P07「货是别人的，价格也是别人的」、P08 五楼那段（两句）。同一句话在大字和字幕上各来一遍，眼睛会被扯两次——尤其这套风格的大字就是「文献原文」的视觉隐喻，字幕再念一遍等于把引文降级成旁白。

**判断标准**：这页有没有一块字号 ≥ 60 的整句文字？有就查一下 cue 号，让位。

## 七、可复用的 12 种页型

新选题优先从这 12 种里拼，别每次从空白画：

| # | 页型 | 干什么 | 主要组件 | ep53 |
|---|---|---|---|---|
| 1 | 双数并置 | 两件事的力量来自同时在场，中间一条竖线 | `Figure`×2 + `VLine` + 比例注脚 | P01 赚 234／花 1,213 |
| 2 | 十年柱 | 一排柱子说「年年加码」，只给最后一根挂读数 | `BarsV` | P02 研发 1.38 万亿 |
| 3 | 目录页 | 一条时间轴 + 三个节点，告诉观众「要讲三次生死」 | `Ruler` + `Soft` | P03 三次差点没过去 |
| 4 | 登记文书 | 泛黄纸面 + 条目 + 朱印，把「事实」变成「档案」 | `Parchment` `Frame` `KV` | P04 1987.09 · 2.1 万 |
| 5 | 拆字 | 一个字一个字圈出来，讲名字/口号/术语 | 单字网格 + `Mark` | P05 中华有为 |
| 6 | 链条 | 三方关系画成一条线，中间写「谁赚差价」 | `Frame`×3 + 箭头 | P06 香港→华为→邮电局 |
| 7 | 大引文 | 一句原话独占一屏，字号 90+ | 裸 `Soft` + `GQuote` | P07 货是别人的 |

| 9 | 落差柱 | 两根柱子 + 一根红标尺 + 少掉的差额 | `BarsV` + 自绘 `<svg>` | P27 8,914→6,368 |

## 九、密度检验

渲之前先自查这四条，比渲完再改省十几分钟：

1. **一页不超过 6 件**（抬头、引用、两个数字、中缝、注脚 = 6，到顶了）。第七件一定是噪音。
2. **正文下沿不超过 880px**。字幕在 948，页脚线在 1022，中间只剩 60px 空隙。
3. **一页一个视觉锤**。这页想让观众记住哪个数？其余都是它的注脚。
4. **派生数要么标算式，要么不进画面**。「日均 6.7 亿」这类数，脚注里写清怎么算的，否则删掉。
