# 版面与组件

这套风格没有相机、没有世界坐标，**只有一张 1920×1080 的纸**。所有位置都是硬坐标，所以网格和字号必须一次定死，否则 36 页排下来会东倒西歪。

## 一、画布网格

```
┌──────────────────────────────────────────────────────────┐ 0
│  YearHeader（左 56, 上 34）        BookCite（右 56, 上 34）│
│                                                          │ 140  抬头带下沿
│      正文区  left 200  ───────────────  right 1720        │
│                                                          │
│                                                          │ 640  横向中缝常用
│                                                          │
│                                                          │ 880  ← 正文下沿硬线
│                    字幕 GSub（y = 948）                   │
│ ─────────────────── 页脚线（bottom 58）────────────────── │ 1022
│  科技简史 · 02      华为 · 1987—2026            14 / 36    │ 1058
└──────────────────────────────────────────────────────────┘ 1080
```

| 量 | 值 | 说明 |
|---|---|---|
| 正文左／右 | 200 / 1720 | 通栏 `RuleFade` 一律 `x=200 w=1520` |
| 抬头带 | y 34–140 | `YearHeader` 字号 64 + caption，`BookCite` 右对齐 maxWidth 560 |
| 横向中缝 | x=960，y 232–760 | `VLine` 的一半页分栏 |
| 正文下沿 | **880** | 脚注 `Note` 起于 880，别往下 |
| 字幕 | y=948 | `GSub` 默认 948；字号按句长 34–46 |
| 页脚 | 线 bottom 58，字 bottom 22 | 三段：系列号 / 时间跨度 / 页码 |

## 二、配色与字体（`theme.ts`）

只用四类：**近黑底、金、象牙白、一种朱红**。多出第五种颜色，这一页就废了。

| 变量 | 值 | 用在哪 |
|---|---|---|
| `G.bg` | `#030303` | 底色（近纯黑） |
| `G.gold` | `#d6b46a` | 主金：年份、线条、标签 |
| `G.goldBright` | `#f3dca0` | 高光金：hot 数值、印章描边 |
| `G.goldDeep` / `G.goldLine` / `G.goldFaint` | 暗金 / 0.55 / 0.18 | 坐标轴、细线、极淡线 |
| `G.ivory` | `#efe6d2` | 正文、标题 |
| `G.ivoryDim` / `G.ivoryFaint` | 0.62 / 0.32 | 次要说明、注脚 |
| `G.red` | `#c8513c` | 朱红：只给「坏消息」和「印章」 |
| `G.parchment` / `G.parchmentDark` | 羊皮纸 | `Parchment` 底座 |

字体 `GF`：数字和西文 `GF.num`（Garamond，等宽感好、数字对齐）、书名 `GF.latinItalic`（Playfair）、中文 `GF.cn`（宋体）。

两个金色函数别用错：

- `goldText(glow)` — **渐变裁剪**，只给 ≥ 60px 的大字。小字用它会底部发褐。
- `goldTextLight(glow)` — 实色 `#f6d98c` + 光晕，给字幕里的数字、引文里的重点词。
- 大数字统一 `goldText(0.6–0.75)`，标题 `goldText(0.45–1)`。

## 三、`kit.tsx`（版面零件库）

```ts
import {Page, FADE, Soft, HLine, VLine, RuleFade, Figure, Col, KV, MiniTable, Tag, Note, Frame, Mark, HBand, BarsV, Ruler, GSub} from '../../library/gilded/kit';
```

| 组件 | 作用 | 关键 props 与坑 |
|---|---|---|
| `Page` | 一页的容器：透明度 + 7px 模糊对拉 + 3% 慢推 | `from/to`（存活区间，相邻页故意重叠 `FADE` 帧）、`anchor`（切点，children 的 `t = f - anchor`） |
| `Soft` | **唯一的出场方式**：透明度 + 9px 模糊收拢 + cubic 缓动 | `at` / `out` / `dur`（默认 18）/ `style`（用它定位 `left/top/width`） |
| `HLine` | 横金线，从左画出 | `x y w dur` |
| `VLine` | 竖金线，从中心往两头长 | `x y0 y1 dur`；分栏用 `x=960` |
| `RuleFade` | 通栏表线，**整条淡入** | 不要用 `HLine` 画通栏——画到一半像一道划痕 |
| `Figure` | 大数字：标签 + 金色巨数 + 单位 | `size`（200–300）、`unit`（中文单位可掉下一行）；**`%` 必须并进 `value`**，否则成了「75 / %」两截 |
| `Col` | 三栏里的一栏（年份 + 线 + 事件 + 数字） | `headAt` 比 `at` 早，先立结构后填数 |
| `KV` | 账页键值行，中间点线 | 值**绝对定位贴 right:0**；值太长会把点线挤没，条目文字要短 |
| `MiniTable` | 带表头的数据表 | `colW` 必填且要和 `w` 对得上 |
| `Tag` | 一条短金线 + 中文条目名 + 拉丁小字 | 放左上或栏首，字号 20 |
| `Note` | 脚注：小竖线 + 两行小字 | 写口径（「归母」「未经审计」「示意」）必用 |
| `Frame` | 描金框 + 四角角标 | 用来「装」文书、产品、一张截图 |
| `Mark` | 朱红叉 / 金勾，14 帧两笔画出 | `kind='x' \| 'check'`，`s` 46–60 |
| `HBand` | 横条比例（国内/海外、净利/研发） | `p` 0–1，`dashed` 表示「另一半」 |
| `BarsV` | 竖柱一组，从基线长出，hot 一根高光 | `base` 是基线 y，`max` 是归一上限；`vals` 只给要标的柱 |
| `Ruler` | 柔和横向刻度尺（时间轴骨架） | `ticks` 字符串数组，刻度字在轴下方 12px |
| `GSub` | 字幕，**直接读 cues** | `skip` 让位；`y` 默认 948 |

## 四、`stage.tsx` / `props.tsx` 里现成的件

| 组件 | 用法 |
|---|---|
| `GildedBg` | 背景光晕 + 暗角。`tone='warm'`（默认）/ `'cool'`；`glow=[x,y]` 是光心 |
| `Dust` / `Grain` | 浮尘 / 胶片颗粒。**挂在 `Page` 外面**，不参与淡化 |
| `YearHeader` | 左上年份抬头。`year` `caption` `prev`（老虎机翻年起点）`rollAt` |
| `BookCite` | 右上文献引用：原版标题斜体 + 《中文名》+ 口径 + 朱印 |
| `GQuote` | 引文块（竖线 + 原文 + 出处），大引文页用它 |
| `Parchment` | 羊皮纸账册，`fs` 字号（**本片用 19–20，默认 15 在 1920 上糊**）、`w` 440–460 |
| `RedStamp` | 朱红印章砸下。`size` 是字号，「断供」两个字 186 实占约 570×335，别按字数估宽 |
| `SealMark` | 静态小印（书名旁、封面） |
| `Smash` / `TitleCard` | 爆点大字 / 片头片尾卡——**长片里基本不用**，那是纯音乐短片的东西 |

## 五、动效语法（只有三种）

1. **柔入**（`Soft`）：这套风格唯一允许的出场方式。透明度 + 模糊一起收。
2. **金线画出**（`HLine` / `VLine` / `Mark`）：线条类才允许「画」，块面类不许缩放入场。
3. **交叉淡化换页**（`Page`）：16 帧重叠，两页同时在场。

**没有**弹入、砸下、位移滑入、缩放弹出。全片唯一的爆点是 `RedStamp`（印章）。这不是审美洁癖——一旦允许弹跳，观众就会开始等「下一件东西蹦出来」，而不是读当前这页。

## 六、踩过的坑（都已在 ep53 修掉）

| 坑 | 现象 | 修法 |
|---|---|---|
| 交叉淡化叠暗底 | 换页中间 0.5 秒整幅发灰 | `GildedBg` / `Dust` / `Grain` 挂在 `Page` **外面**，只让内容层淡化 |
| `Parchment` 固定 15px | 1920 上中文键值糊成一团 | `fs` 参数，本片 19–20；`w` 同步加到 440–460 |
| `KV` 用 flex 推右值 | 长值（「电源业务（安圣电气）」）被推出右边界压到竖线上 | 值绝对定位 `right: 0`，点线加 `paddingRight` 让位 |
| `Figure` 的 `unit="%"` | 「75」下面单独挂一个「%」 | 百分号并进 `value="75%"`，不给 unit |
| 两栏字号不同 | 「亿元」一高一低 | `Figure` 内部用固定高度盒 + `align-items: flex-end` 对齐底线 |
| 字幕句间重叠 | 换句时两句叠成一团残影 | `outAt = min(c.end + 0.22, next.start - 0.03)`，淡出 7 帧 |
| 裸 `<g>` / `<line>` / `<text>` | 落差线、虚线标签**完全不渲染**（HTML 里没有 SVG 上下文） | 自绘图表一律 `<svg width={1920} height={1080}>` 包起来 |
| 虚线标签右对齐在 x1 | 标签和柱顶读数叠住 | 标签移到线右端之外，分两行 |
| `RedStamp` 4 个字 | 溢出框、压住别的元素 | 最多 2–3 字；4 字要拆成两行或缩 `size` |
| 长引文挤成一团 | `Parchment` 里塞长英文，点线对不齐 | `Parchment` 只放短键值（≤6 字），长句用 `GQuote` |
| 画面标题照抄口播 | 同一句在标题和台词各来一遍 | 标题写**论点**，台词说**事实**（见下） |
| 页码与页数不一致 | 页脚显示 37 / 36 | 页码由 `CUTS.filter(c => c <= f).length` 算，别手写 |

## 七、画面标题的四条自查

1. **标题不许和口播一字不差**。ep53 原来 P16 写「命门不能攥在别人手里」（台词原句），改成「一次官司，换来一条底线」；P32「它历史上最好的上半年」删掉换拉丁 `HALF-YEAR RECORD`。
2. **标题是论点，不是描述**。「营收 4,678 亿」是描述，「钱去哪了，看研发就明白」是论点。
3. **一页只有一个标题**。抬头（年份）不占标题的位置，它属于时间坐标。
4. **拉丁小字只做装饰**（`Tag` 的 `latin`、`Figure` 的 `label` 用中文），别用英文解释内容。
