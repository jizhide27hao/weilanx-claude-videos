# 装配与交付

零件库（`kit.tsx`）和一页一页的内容（`film-a-pages*.tsx`）都写完之后，总装只有 160 行。这份文档给的是**可以直接抄的骨架**、音效纪律、渲染验收命令，以及封面和交付清单。

## 一、文件分工

```
src/episodes/<期>/
├── film-a-pages1.tsx    P01–P12（第一幕）
├── film-a-pages2.tsx    P13–P24（第二幕）
├── film-a-pages3.tsx    P25–P36（第三幕）
├── film-a.tsx           CUTS + PAGES + FilmA + 音效表   ← 总装
├── cues.ts / cues.json  字幕时间轴（tts.py 生成，不要手写）
├── CoverTallGilded.tsx  3:4 竖版封面（1080×1440）
├── Cover43Gilded.tsx    4:3 横版封面（1440×1080）
└── CoverWideGilded.tsx  16:9 横版封面（1920×1080）
```

**为什么拆三份**：单文件 1700 行时，改 P27 要滚半天；拆成三幕后每份 470–570 行，一屏能找到。拆的位置跟着「幕」走，不要按 12 页机械切。

每页一个 `export const PNN: React.FC<{t: number}>`，**只吃一个 `t`**（页内帧，0 = 切点）。不要传 `f`、不要传全局帧——一页一旦知道自己在全片的位置，就会有人写出「第 4000 帧时出现」这种没法复用的代码。

## 二、`film-a.tsx` 骨架（照抄）

```tsx
import React from 'react';
import {AbsoluteFill, Audio, Sequence, staticFile, useCurrentFrame} from 'remotion';
import {CUES, DURATION} from './cues';
import type {SfxCue} from '../../library/types';
import type {Mix} from '../../library/Show';
import {Dust, GildedBg, Grain} from '../../library/gilded/stage';
import {FADE, GSub, Page} from '../../library/gilded/kit';
import {G, GF} from '../../library/gilded/theme';
import {P01, /* … */ P12} from './film-a-pages1';
import {P13, /* … */ P24} from './film-a-pages2';
import {P25, /* … */ P36} from './film-a-pages3';

const PAGES = [P01, P02, /* … */ P36];
export const CUTS = [0, /* cf(n)-6 … */];
export const FILM_A_FRAMES = DURATION;

export const FilmA: React.FC<{mix?: Mix}> = ({mix = 'all'}) => {
  const f = useCurrentFrame();
  const on = (m: Mix) => mix === 'all' || mix === m;

  return (
    <AbsoluteFill style={{background: G.bg, overflow: 'hidden'}}>
      {/* 底色、浮尘、颗粒挂在 Page 外面：不参与交叉淡化，否则中间会发暗 */}
      <GildedBg f={f} tone="warm" glow={[48, 40]} />
      <Dust f={f} n={54} seed={7} />

      {PAGES.map((P, k) => {
        const a = CUTS[k];
        const from = k === 0 ? 0 : a - FADE;
        const to = k === PAGES.length - 1 ? FILM_A_FRAMES : CUTS[k + 1] + FADE;
        return (
          <Page key={k} f={f} from={from} to={to} anchor={a}>
            {(t) => <P t={t} />}
          </Page>
        );
      })}

      <GSub f={f} cues={CUES} y={948} skip={[/* 同文让位的 cue 号 */]} />

      {/* 页脚：一条细线 + 系列号 / 跨度 / 页码 */}
      <div style={{position: 'absolute', left: 76, right: 76, bottom: 58, height: 1,
        background: `linear-gradient(90deg, rgba(214,180,106,0.32), rgba(214,180,106,0.1), rgba(214,180,106,0.32))`}} />
      <div style={{position: 'absolute', left: 76, right: 76, bottom: 22, display: 'flex',
        justifyContent: 'space-between', fontFamily: GF.cn, fontSize: 15, letterSpacing: 3, color: G.ivoryFaint}}>
        <span>科技简史 · 02</span>
        <span>华为 · 1987—2026</span>
        <span>{String(Math.min(PAGES.length, CUTS.filter((c) => c <= f).length)).padStart(2, '0')} / {PAGES.length}</span>
      </div>

      <Grain opacity={0.12} />

      {on('voice') && <Audio src={staticFile('audio/<期>/voice.wav')} />}
      {on('bgm') && <Audio src={staticFile('audio/<期>/bgm.wav')} volume={0.92} />}
      {on('sfx') &&
        GILDED_FILM_SFX.map(([name, at, vol], i) => (
          <Sequence key={i} from={Math.max(0, at)} durationInFrames={54} layout="none">
            <Audio src={staticFile(`audio/sfx/${name}.wav`)} volume={vol} />
          </Sequence>
        ))}
    </AbsoluteFill>
  );
};
```

页脚的中间段（`华为 · 1987—2026`）是这一期的**时间和对象**，换成自己的。系列号第一集从 `01` 起，demo 不占号。

## 三、音效纪律（这是最容易做砸的一环）

**只在换章和落结论时出声，数字落位一律静默。** 36 页如果每页都 whoosh，就成了综艺。

ep53 全片 265 秒只给 **21 声**：

| 类型 | 用在哪 | 音量 |
|---|---|---|
| `whoosh` | 换章（每组第一页） | 0.34–0.46 |
| `paper` | 文书翻开、引文卡 | 0.28–0.34 |
| `stamp` | 印章砸下（实体清单、结论） | 0.4–0.7 |
| `ding` | 关键数字落点 | 0.32–0.36 |
| `error` | 负增长、落差、断供 | 0.3–0.38 |
| `type` | 开头滚字 | 0.2 |

写法：`['whoosh', CUTS[14], 0.4]`——**用 `CUTS[k]` 而不是写死帧号**，这样改切点后音效自动跟随。落在页内的用 `CUTS[k] + 页内偏移`。

## 四、注册（`src/Root.tsx`）

在 `<Folder name="05-暗金文献风">` 里加三行：

```tsx
<Composition id="<期>-gilded" component={FilmA} durationInFrames={FILM_A_FRAMES} fps={FPS} width={1920} height={1080} defaultProps={mix} />
<Still id="<期>-cover-tall-gilded" component={Ep<NN>CoverTallGilded} width={1080} height={1440} />
<Still id="<期>-cover-wide-gilded" component={Ep<NN>CoverWideGilded} width={1920} height={1080} />
```

**横版和竖版是两个 Still，不是一张图的两个尺寸**——构图完全不同（竖版上下堆、横版左右分），缩放做不到。

`mix` 是共用的声道开关（`voice` / `bgm` / `sfx` / `all`），照抄别的期。注册完 `node node_modules/typescript/bin/tsc --noEmit -p tsconfig.json` 必须过。

## 五、渲染与验收

```sh
export NODE_OPTIONS=--max-old-space-size=4096
node node_modules/@remotion/cli/remotion-cli.js render src/index.ts <期>-gilded out/<期>/成片/<期>-gilded.mp4 \
  --concurrency=4 --crf=24 --log=error
```

8000 帧、concurrency=4，约 12 分钟。渲完三件事：

```sh
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,width,height,sample_rate,channels -of default=nw=1 out/<期>/成片/<期>-gilded.mp4
ffmpeg -hide_banner -i out/<期>/成片/<期>-gilded.mp4 -af volumedetect -f null - 2>&1 | grep -E "mean_volume|max_volume"
ffmpeg -hide_banner -loglevel error -ss 55 -i out/<期>/成片/<期>-gilded.mp4 -frames:v 1 -y out/<期>/抽帧/v-55.png
```

合格线（ep53 实测）：

| 项 | ep53 | 判据 |
|---|---|---|
| 时长 | 265.69s | 和 `DURATION / 30` 差 < 0.1s |
| 体积 | 41.9MB | CRF 24，45MB 上下正常 |
| 均值响度 | −22.2dB | −22 ± 1 |
| 峰值 | −3.1dB | 不高于 −3 |

**抽帧必须从成片抽**，不能只看 Studio 截图：淡化过渡、字幕让位、页码都只有成片里才对。抽查点：每组的第 1 页（换章）、所有 3 秒短页（最容易来不及）、结尾页。

## 六、封面：三版都要出

原 Vox 封面是网点照 + 荧光钩子条，和这套风格不搭，必须另做。
**16:9 / 4:3 / 3:4 各写一个组件**——竖版上下堆、横版左右分、4:3 是横版收窄，三张不是缩放关系，改一张救不了另外两张。

| 量 | 竖版 `CoverTallGilded.tsx` | 横版 `CoverWideGilded.tsx` |
|---|---|---|
| 画布 | 1080×1440 | 1920×1080 |
| 结构 | 上 2/3 放数据线，下 1/3 放文字 | 左半幅立字，右半幅放数据线 |
| 主标题 | **214px**，两行，top 232 / 452 | **152px**，两行，top 186 / 350 |
| 收边金线 | top 720，宽 700 | top 542，宽 620（另在 top 678 补一条 520 的渐隐线封口） |
| 副题 | top 752（34px）+ 806（24px） | top 566（30px）+ 612（22px） |
| 数据线 | X 96–984，BASE 1150 / TOPY 850 | X 1024–1724，BASE 742 / TOPY 262 |
| 钩子 | top 1234，54px | top 878，46px（**画面 86% 处**，比例同竖版） |
| 朱印 | right 92 / top 1216 | right 96 / top 898 |
| 页脚 | bottom 72 | bottom 46 |

底都一样：`GildedBg`（暖光晕偏左上）+ `Dust` + `Grain(0.13)`，不要照片、不要贴纸。

### 4:3 版（1440×1080）`Cover43Gilded.tsx`

横向收窄 480px，**纵排节奏和 16:9 保持一致**（钩子仍压 878、朱印 898、页脚贴底 46），只重算横向与字号。下面是起点值，**首次落版必须 Read 抽检再微调**：

| 量 | 16:9 | 4:3 |
|---|---|---|
| 主标题 | 152px，top 186 / 350 | 134px，top 186 / 330 |
| 收边金线 | top 542，宽 620 | top 542，宽 520 |
| 副题 | top 566（30px）/ 612（22px） | top 566（27px）/ 610（21px） |
| 数据线 | X 1024–1724（宽 700），BASE 742 / TOPY 262 | X 748–1288（宽 540），BASE 742 / TOPY 262 |
| 钩子 | top 878，46px | top 878，42px |
| 朱印 | right 96 / top 898 | right 60 / top 898 |

**两条额外规则**：① 数据线右端必须停在 1288 以内，再往右会和朱印、页脚挤成一块；② 左栏字宽要重新量——152px 的标题在 700 宽里塞得下但挤掉金线间距，134px 才留得出来。**别把 16:9 直接裁成 4:3**，右侧数据线会被切掉一半。

### 横版三条硬规则

1. **右侧留 240–260px 的角标区**（时长、UP 头像、平台水印），主体信息不许进去。ep53 的数据线右端停在 1724，就是给这留的。
2. **只留一个数**。竖版能塞「2.1 万块起家 / 8,809 亿收尾」两个，横版塞三个就没人读了。
3. **第一组要有线收边**。标题 + 副题 + 数据线是「第一组」，钩子是「第二组」；两组之间空 260px 是呼吸，但不给第一组收边就像半成品。

### 自检

竖版缩到 **300px 宽**、横版缩到 **480px 宽**，各看三件事：**主标题认得出、钩子读得完、印章不糊**。竖版主视觉区（上 2/3）不许有元素压到标题带（top 720 以下留给文字）。

## 七、发布文案与核查表

复用 `weilanx-creator-timeline-video` 的两个脚本和两份参考，**不要重写**：

```sh
python .workbuddy/skills/weilanx-creator-timeline-video/scripts/doc.py --ep <期>   # 文稿 + 核查表
```

- 抖音标题：主推 1 个 + 备选 2 个，≤ 25 字，数字必须和片里一致。
- 描述**一句话，≤ 32 字**：只补标题没说的那半句，不重复标题、不串时间节点。紧跟一行 `数据截至 … · 不构成投资建议` + 5–8 个话题。
- 事实核查见 `weilanx-creator-timeline-video/references/事实核查.md`，**配音前**做完第一轮。

## 八、交付清单

**全部落在 `out/<期>/` 里按类型分开**（`node .../out-dir.mjs <期>` 建目录）：

| 文件 | 说明 |
|---|---|
| `out/<期>/成片/<期>-gilded.mp4` | 1920×1080 / 30fps / H.264 + AAC |
| `out/<期>/封面/封面-16x9.png` | 1920×1080 横版封面（B 站 / YouTube / 视频号） |
| `out/<期>/封面/封面-4x3.png` | 1440×1080 横版封面（抖音横版 / 公众号首图） |
| `out/<期>/封面/封面-3x4.png` | 1080×1440 竖版封面（抖音 / 小红书） |
| `out/<期>/文案/发布文案.md` | 标题 3 个 + 描述 + 话题 |
| `out/<期>/文档/<期>-口播文稿与事实核查.md` | 文稿 + 逐条核查 + 修正记录 |
| `out/<期>/抽帧/` | 按页抽的自查帧，交付后可留可删 |
| `audio/<期>/voice.wav` / `bgm.wav` | 人声 / 配乐 |
| `audio/episodes/<期>.mjs` | 配乐总谱 |

**不许再把 mp4 / 封面 / 文案平铺在 `out/` 根目录。** 旧期散落文件用 `out-dir.mjs <期> --archive` 看清单、`--apply` 收进去。

交付报告要写清六件事：规格与响度、页数与分页逻辑、**这一版和上一版（Vox/长卷版）的差别**、核查改了什么、替他定了什么、听感只能他自己听。
