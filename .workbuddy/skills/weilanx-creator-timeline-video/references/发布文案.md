# 封面与发布物料

导出成片之后必须一起交的五样：**16:9 横版封面**、**4:3 横版封面**、**3:4 竖版封面**、**抖音标题**、**抖音描述**。这一步不用等用户确认，按下面的规则自己定，交付时一起给。

**三版封面都要出，不是三选一**——16:9 是 B 站 / YouTube / 视频号 / 公众号的，4:3 是抖音横版和部分公众号首图的裁切比例，3:4 是抖音 / 小红书的竖版。同一个选题，观众在三个平台第一眼看到的不是同一张图。

## 一、16:9 横版封面（1920 × 1080）

**就是片子的第 0 帧**，`Cover.tsx` 里的 `Ep<NN>Cover` 一稿两用：片头当封面演，导出时再单独渲一张图。

```sh
node_modules/@remotion/cli/remotion-cli.js still src/index.ts <期>-cover-wide out/<期>/封面/封面-16x9.png
```

`Root.tsx` 注册：`<Still id="<期>-cover-wide" component={Ep<NN>Cover} width={1920} height={1080} />`。

**组件 props 必须是 `{f?: number}`**——写成 `{f: number}` 时 `Still` 不传参，TS 直接报错、整个 Root 编不过（ep53 踩过）。

### 排版规则（横版和竖版差别很大，别把竖版直接缩）

- **左半幅立字，右半幅放主视觉**（命运线 / 产品 / 人物）。1080 的高度放不下竖版那四层，上下堆一定挤。
- **标题字号约为竖版的 70%**（竖版 186 → 横版 130–150）。再大就压到右边。
- **右侧留 240–260px 的角标区**（时长、UP 头像、平台水印），主体信息不许进去。
- **只留一个数**。竖版能塞「起家 → 收尾」两个数，横版塞三个就没人读了。
- 钩子压在画面 **86% 高处**（竖版是 `1234 / 1440`，同一个比例）；中间的大片留白是呼吸，但第一组（标题 + 副题 + 主视觉）要有一条线收边，否则像半成品。
- 颜色、系列号、时间跨度标记的规则和竖版一致（见下一节）。

自检：缩到 **480px 宽** 看一遍，标题认得出、钩子读得完。

## 二、4:3 横版封面（1440 × 1080）

抖音横版、部分公众号首图的裁切比例。**不是把 16:9 缩小，也不是裁一刀**——1440 的宽度放不下 16:9 的「1060 黑卡 + 690 图纸」，必须重新排。

用公共模板 `src/library/vox/Cover43.tsx` 的 `VoxCover43`：左黑卡上的字全由 props 给，右栏主视觉用 `visual` 传进去（按 1440×1080 画布坐标绝对定位）。ep56 是第一个用的。

```tsx
import {VoxCover43} from '../../library/vox/Cover43';

export const Ep<NN>Cover43: React.FC<{f?: number}> = () => (
  <VoxCover43
    index="05"
    kicker="钩子标签"
    title={['主标', '副标']}
    years="2010—2026"
    hook="一句话钩子"
    visual={<>…图纸 / 照片 / 贴纸…</>}
  />
);
```

`Root.tsx` 注册：`<Still id="<期>-cover-43" component={Ep<NN>Cover43} width={1440} height={1080} />`

```sh
node node_modules/@remotion/cli/remotion-cli.js still src/index.ts <期>-cover-43 out/<期>/封面/封面-4x3.png
```

### 和 16:9 的坐标差异

| 元素 | 16:9（1920） | 4:3（1440） |
|---|---|---|
| 黑卡 | `60,60 / 1060×960` | `44,50 / 700×980` |
| 主标题 | 190px | 168px |
| 年份 | 108px | 94px |
| 钩子 | 50px | 42px |
| 右栏 | x 从 1170 起，690 宽 | x 从 792 起，610 宽 |
| 图纸 | 690×470 | 570×400 |
| 系列号 `科技简史 · NN` | 贴年份右侧（x 700） | 卡片底部（`96,944`），年份右边放不下 |

### 排版规则

- **钩子 ≤ 15 字**。42px 一行、黑卡内宽 610，再长就顶到卡边。
- **右栏标签只贴四角**：图纸左上放断崖标注、右上放峰值、右下放刻度说明。标签压在中段一定盖住曲线和黑圈。
- **黑圈要套在折点上**，不是套在段线上。16:9 那版第一个圈比折点低 40px，收到 4:3 之后偏移更扎眼。
- 右栏下方（照片说明以下、y > 920）只放一句红字判断，不要再塞第二个物证。

## 三、3:4 竖版封面（1080 × 1440）

**代码渲染，不用 AI 生图**。用这一期的道具拼出来，风格和片子一致。

```sh
node_modules/@remotion/cli/remotion-cli.js still src/index.ts <期>-cover-tall out/<期>/封面/封面-3x4.png
```

### 排版规则

- **尺寸固定 1080 × 1440**，在 `Root.tsx` 注册成 `<Still id="<期>-cover-tall" ... width={1080} height={1440} />`。
- **上半 2/3 放主视觉**（人物 / 产品 / 那条曲线），**下半 1/3 放标题**。手机在信息流里一屏只露 3:4 的上半部，标题压在下 1/3 才不会被裁。
- **主标题 ≤ 14 字**，或拆成「主标题 + 副标题」两行。这一期的写法是「小米 16 年」+ 副题「一碗粥，到 7000 亿」。
- **字号**：主标题 130–170px，副题 40–56px。小于 40 在手机上看不见。
- **留白 ≥ 60px**，四边都要留。
- **颜色只用片子里的两种主色**（这一期是旧纸米色 + 朱红），加一种重色做强调就够，不要超过三种。
- **必须有的三个元素**：主标题、一个可辨认的视觉符号（logo / 产品 / 曲线）、一个「时间跨度」标记（`2010—2026`）。
- **左上角的系列号 `科技简史 · NN`**（模板 `src/library/vox/CoverTall.tsx:40` 硬编码，本期只在 `CoverTall.tsx` 传 `index`）：**demo 期（ep18 的 AI 简史、ep19 的苹果、ep20 的英伟达）不占编号**，正式系列第 1 期是 `01`，之后逐期 +1。新开一期时先看上一期 `CoverTall.tsx` 里的 `index` 再决定，**不要用项目期号（ep52 这类）当系列号**。

### 这一期踩的坑

- **道具压字**：`CarSide` 放在左下角，正好压在副标题上。规则是**任何道具都不能进入标题的矩形区域**（下 1/3 减去 60px 边距）。
- **元素太多**：第一版塞了 logo、车、手机、曲线四样，缩到手机尺寸后全糊。**3:4 封面上最多 3 个视觉元素**。
- 渲完必须 Read 看一眼，不要相信「代码里看起来对」。

## 四、抖音标题

**一个主推 + 两个备选**，交付时都给出，说明推荐哪个。

### 公式（选一个用）

| 公式 | 结构 | 例子 |
|---|---|---|
| 数字反差 | 「A 变成 B」+ 时间跨度 | 16 年，一碗粥变成 7000 亿 |
| 悬念缺口 | 反常事实 + 未解的问 | 市值腰斩，车却月卖 4 万台 |
| 处境代入 | 「你也…」+ 结论前置 | 从 1999 到 25 万，性价比救不了它 |
| 数字清单 | 「三次 / 五年 / 两件事」 | 小米 16 年，三次差点死掉 |

### 硬规则

- **≤ 25 字**（抖音列表页大约只展示 20–22 字，超出会被截断）。
- **前 8 个字必须有信息**，不要「今天我们来聊聊…」这种开场。
- **不用问号堆砌**，最多一个。
- **不用「震惊」「必看」「99% 的人不知道」** 这类已经失效的词，会被判定为标题党降权。
- 标题里的数字**必须和片里一致**。片里说「近 7000 亿」，标题不能写「7000 亿」当准确值。
- 不放话题标签（标签写在描述里）。

## 五、抖音描述

**一句话就够了。** 抖音信息流里描述只露标题下面一两行，写五段没人展开——多写的部分等于没写。

这一段唯一的作用是：**补上标题没说出口的那半句**。标题放数字，描述就给判断；标题给悬念，描述就给结论。

```
一句话（≤ 32 字）

数据截至 YYYY-MM-DD · 不构成投资建议
#标签 5–8 个
```

### 硬规则

- **正文只有一个句子，≤ 32 字**，一个句号收尾。想多说的话，往标题里压。
- **不重复标题**。标题已经说了「50 万起家、6.7 万亿登顶」，描述再念一遍是浪费曝光位。
- **不写 `→` 时间节点流水账**。那是片子干的事，没人会在描述里读十年编年史。
- **合规两行压成一行附属**（`数据截至 … · 不构成投资建议`），**不能省**——财经内容不写容易被限流；但它挂在句号后面，不占正文位。
- 标签一行，5–8 个，规则见本节末尾。
- 想写长？去写**小红书正文**，那里可以长，也本来就该长。

### 例子（阿里那期）

标题：`50 万起家，6.7 万亿登顶，如今 1.95 万亿`
描述：`三次上市、一次退市、两次腰斩，它每次跌下去都换了一套活法。`

标题给三级台阶，描述给判断——两边不重复，合起来才是一条完整的钩子。

## 六、财经类内容的合规红线

时间轴长卷讲的基本都是公司史，属于财经内容，注意：

1. **不预测股价、不给买卖建议**，不写「还会涨」「抄底」。
2. **不出现「稳赚」「必涨」「翻倍」**。
3. **市值 / 股价必须标时点**（「截至 2026 年 10 月」），否则过两周就成了错误信息。
4. **亏损、裁员这类负面信息只用公开披露的口径**，不加形容词。
5. 涉及「第一」「最」这类排名，标口径（中国 / 全球、出货 / 销量）。

## 七、交付清单

每期固定交付这几样，**全部落在 `out/<期>/` 里按类型分开**（`out-dir.mjs` 建目录）：

| 文件 | 说明 |
|---|---|
| `out/<期>/成片/<期>.mp4` | 成片 1920×1080 / 30fps / H.264 + AAC |
| `out/<期>/封面/封面-16x9.png` | 1920×1080 横版封面（B 站 / YouTube / 视频号） |
| `out/<期>/封面/封面-4x3.png` | 1440×1080 横版封面（抖音横版 / 公众号首图） |
| `out/<期>/封面/封面-3x4.png` | 1080×1440 竖版封面（抖音 / 小红书） |
| `out/<期>/文案/发布文案.md` | 标题 3 个（标注推荐）+ 描述全文 + 话题 |
| `out/<期>/文档/<期>-口播文稿与事实核查.md` | 文稿 + 逐条核查 + 修正记录 |
| `out/<期>/抽帧/` | 自查帧，交付后可留可删 |
| `audio/<期>/voice.wav` | 人声轨道（要换真人录音时覆盖它） |
| `audio/episodes/<期>.mjs` | 配乐总谱源码 |

**不许再把 mp4 / 封面 / 文案平铺在 `out/` 根目录。** 一期一个文件夹，两期连着做也不会串。旧期散落文件用 `out-dir.mjs <期> --archive` 看清单、`--apply` 收进去。

Studio 地址 `http://localhost:3000/<期>` 也算交付物之一，方便用户逐帧看。
