# 暗金文献风

![预览](预览.jpg)

讲历史、科学、数学的横屏 16:9 风格，像一部在烛光下翻古籍的纪录片：近黑底、金色细线、衬线字，每个年代用「年份抬头 + 文献引用」开场。画面语法是从一支参考视频里拆出来的（参考视频不进 git），组件和示例都是重写的，没有沿用原片的内容、文案和水印。

## 画面特征

- **底色**：几乎纯黑（≈ #030303），中间一团呼吸的暖光晕（安静、哲思段落换成冷蓝光晕），四周暗角，上面盖一层胶片颗粒和缓慢漂移的金色浮尘
- **配色只有四类**：黑底、金（年份、线条、重点词）、象牙白（正文、骰子、纸）、一种朱红（印章、劣势一方、高亮路径）
- **字体**：数字和西文用 Garamond，中文用宋体粗；西文书名一律斜体
- **固定版式**：左上角年份抬头（金色大年份 + 渐隐金线 + 「地点 · 人物」），右上角文献引用（原文斜体书名 + 金色《中文书名》+ 作者年份 + 朱红小印），底部居中字幕，重点词变金
- **出场方式**：所有元素都是「模糊 + 透明」一起柔入，不弹不跳；字幕逐字柔入；场与场之间带模糊的交叉淡化；镜头整体缓慢推近 2–3%
- **换年代**：年份数字像老虎机一样一位一位往上翻
- **图表全是金线**：细金线逐步画出，端点发光；要强调的那条路径改成发光朱红
- **实物有质感**：象牙骰子（1 点朱红）、金币（可切出扇形表示比例）、羊皮纸账册、描金边对比卡、朱红印章砸下来
- **硬切极少**：整片 130 秒只有 7 个硬切，其余都是同一个画面里元素的进出

## 长片版（翻页）

ep53 的 A 版把这个风格从「30 秒短片」拉到 4 分 26 秒，语法只改了三处：

- **不用相机**：一页一张「账页」，硬坐标、定幅 1920×1080，一页 6–9 秒。
- **换场只溶不切**：相邻页重叠 16 帧、7px 模糊对拉、整页 3% 慢推；底色 / 浮尘 / 颗粒挂在页外，否则换页中间整幅发灰。
- **一页同屏摊 6–8 件**：抬头、文献引用、两个数字、中缝、注脚同时在场，观众自己决定看哪儿——这是它和「无口播短片」最根本的差别，短片靠爆点牵着走，长片靠并置说话。

工作流见 skill `weilanx-creator-gilded-long-video`（分页算法、页型清单、版面网格、装配骨架都在里面）。
