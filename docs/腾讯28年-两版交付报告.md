## 一、一句话结论

两版都按「97 句 / 4 分 30.8 秒」的同一份配音做完，**同一条时间轴、同一批数据、同一份核查结论**；差别只在叙事方式——长卷版是一台相机在 30,000px 的桌面上推拉，暗金版是 36 页文献一页页翻过去。

## 三、两版到底差在哪

| | ep56 长卷版 | ep57 暗金版 |
|---|---|---|
| 观众的感觉 | 在一张超大书桌上被推着走 | 一页一页翻档案 |
| 信息密度 | 高：一屏 5–8 件，靠相机引导 | 低：一页 3–6 件，靠淡入排序 |
| 空间逻辑 | 连续（世界坐标、镜头有惯性） | 离散（每页独立构图，页间只溶不切） |
| 情绪落点 | 命运线对数刻度（市值红线贯穿全片） | 朱印（没卖 / 出招 / 珍珠港 / 顶 / 十年最低） |
| 适合的平台 | 抖音（前 3 秒信息密度定生死） | B 站 / 小宇宙（允许慢，允许留白） |
| 复用成本 | 改一处坐标要重算相机 | 改一页不影响邻页 |

两版刻意做得不像同一个模板：长卷版是青灰纸 + 朱红压字，暗金版是近黑底 + 金线 + 朱印，缩略图并排一眼能分清。

## 五、修复过程备忘（本轮踩坑）

1. **ep57 首渲报 `Sequence from NaN`**：SFX 音效表是按含 P03 的 37 页序写的 `CUTS[k]`，删掉 P03 后数组左移一位——所有 k≥2 的音效错位一页，末尾 `CUTS[36]` 越界取到 undefined → NaN。整表按新页序重排，并在渲染处加 `Number.isFinite(at)` 兜底过滤。
2. **ep56 配乐全轨静音**：writeScore 里一个音符取了小数数组索引（`(k/2)%4`）得到 undefined → NaN → RMS gain=NaN → 全轨 NaN。改为 `Math.floor(k/2)%4`，分段响度报告恢复正常。
3. **SFX 用了不存在的音效名**（boom/fall）：渲染 404。可用清单以 `public/audio/sfx/` 为准（boing click confetti ding error magic paper pop question shake snip stamp type whoosh）。
