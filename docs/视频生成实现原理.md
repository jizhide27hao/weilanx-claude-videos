# 代码生成视频 · 实现原理

> 这份文档只讲**怎么做出来的**，不讲工程细节。读完应该能自己写出"让 AI 做一期这种视频"的提示词。

---

## 一、一句话原理

**视频 = 一串图片。每一张图片 = 一个函数在某一个帧号上的求值结果。**

- 帧率 30fps → 时长 4 分 15 秒 = 7658 张图
- 第 n 张图对应 `时间 = n / 30` 秒
- 没有"拍摄"、没有"剪辑时间线"、没有"AI 生成画面"

写视频 = 写一个 `render(帧号) → 这一帧长什么样` 的函数。所谓"动画"，就是这个函数返回值的连续变化。

---

## 二、四个核心概念

### 1. 帧号是唯一的时间单位

所有时间都换算成整数帧。**不允许出现"1.5 秒后出现"这种写法**，只允许"第 45 帧出现"。

好处：任意一帧可以单独渲染、单独检查、单独重做，成本接近零。

### 2. 动画 = 某属性在一个帧区间内从 A 推到 B

唯一的动画原语是一个"进度"：

```
进度 p = 夹紧((当前帧 - 开始帧) / 持续帧数) → 再套一条缓动曲线
属性值 = A + (B - A) × p
```

六条缓动曲线决定全部质感：

| 曲线 | 感觉 | 典型用途 |
|---|---|---|
| 线性 | 机械 | 进度条、粒子漂移 |
| 缓出（easeOut） | 干脆利落 | 元素入场、场景淡入 |
| 缓入缓出 | 有惯性 | 相机推拉 |
| 过冲回弹（easeOutBack） | 卡通、有生命 | "啪"地弹出 |
| 弹性（easeOutElastic） | Q 弹夸张 | 重磅元素 |
| 减速滑停（tailEase） | 摄影机感 | 相机到位 |

**同一个动作换一条曲线就是另一种风格。** 这是全部"动效设计"的旋钮。

### 3. 时间锚点 = 口播的句子

画面不按秒排，按**句子**排：

| 锚点 | 含义 |
|---|---|
| `cf(n)` | 第 n 句口播开口的那一帧 |
| `cw(n, '词')` | 第 n 句说到某个词的那一帧 |

惯例：**场景在 `cf(n) - 6` 切入**（画面比声音早 6 帧，0.2 秒），观众"先看到，再听到"。

这样做的收益：重录口播后，所有动画自动重新对齐，一秒代码都不用改。代价：改文案时不能增删句子，否则后面所有 `cf(n)` 错位。

### 4. 声音和画面共享同一组锚点

音效不是"贴上去对齐"的，它和画面引用同一个帧号数字。所以"印章砸下""音效响起""字幕出现这个词"是同一个整数——**不是对齐出来的，本来就是同一个值。**

---

## 三、一帧是怎么搭出来的

一帧是 6 层叠出来的（从下往上）：

| 层 | 内容 | 是否随内容变化 |
|---|---|---|
| 背景 | 点阵纸 / 旧纸桌面 / 近黑底 + 暖光晕 | 全片恒定 |
| 场景 / 世界 | 真正的内容层，元素在这里进出 | 每秒都在变 |
| 章节标签 | 左上角或顶部的序号 + 标题 | 按段落变 |
| 字幕 | 当前该显示的那一句 | 按句变 |
| 颗粒 / 纸纹 | 静态噪点，压掉"数字画面太干净"的感觉 | 恒定 |
| 封面 | 片子第 0 帧，之后淡出 | 只有开头 |

音轨不在画面里，是独立的三条：人声、配乐、音效。

---

## 四、动画只有三种基本运动

| 类型 | 驱动方式 | 例子 |
|---|---|---|
| **入场 / 出场** | 区间进度 0→1（或 1→0） | 弹出、上浮、缩着淡出 |
| **状态切换** | 帧阈值，瞬间换 | 表情从"茫然"变"星星眼"、印章砸下 |
| **连续循环** | 正弦函数 | 呼吸、眨眼、浮尘、轻微摇晃 |

连续循环有个关键技巧：**每个元素用自己坐标算一个相位偏移**，天然错峰。不需要全局调度器，一组元素要同步就让它们共用坐标。

### 常用动效对照（写提示词时可以直接点菜）

| 动效 | 参数 |
|---|---|
| 弹出 | 起始帧、持续 10 帧、过冲回弹 |
| 上浮 / 左右滑入 | 起始帧、位移 120px、淡入 |
| 缩着淡出 | 结束帧前 8 帧、缩到 0.9 倍 |
| 抖一下强调 | 起始帧、振幅 12px、3 个来回后衰减 |
| 手绘逐格抖动 | 每 7.5 帧换一次随机值（≈4fps），不是逐帧 |
| 冲击爆发线 | 起始帧、10–16 根线、半径外扩 + 透明度衰减 |
| 漫画集中线 | 40 根线，每 3 帧换一次随机种子产生震颤 |
| 情绪气泡 | 上浮 `-0.8px/帧` + 轻微旋转，40 帧后消失 |
| 线条生长 | 长度按进度从 0 长出来，两端渐隐 |
| 相机推拉 | 关键帧插值，缩放走**对数**插值才自然 |
| 翻页溶解 | 两页重叠 16 帧，透明度三角波 + 模糊收放 |

**所有随机都是"确定性"的**：给定种子，结果永远一样。这不是洁癖——只有这样才能并发渲染、中途抽帧检查。

---

## 五、画面骨架三选一（决定整体形态）

| 骨架 | 视觉特征 | 转场 | 适合题材 |
|---|---|---|---|
| **场景切播** | 一屏一个概念，卡片/窗口/小人 | 淡入 + 上移淡出，约 10 帧 | 科普、概念拆解、口播短片 |
| **翻页账本** | 近黑底 + 暖光 + 金线 + 衬线字，一页一张"账" | **只溶不切**，相邻页交叉淡化 16 帧 + 模糊 | 公司史长片、文献感、严肃叙事 |
| **相机长卷** | 一条 26500px 的旧纸桌面，时间尺横贯全片，节点钉在年份上 | 一镜到底，无切镜 | 发展史、时间跨度长的线索 |

三者的共性：**画面全由代码画（矩形、圆、路径、文字），没有真实素材**（Vox 拼贴风例外，会嵌真实照片和视频）。

---

## 六、节奏规则（风格的核心，最该写进提示词的就是这些数字）

| 项 | 规则 |
|---|---|
| 单句长度 | 8–20 字，最长不超过 26 字 |
| 一句话一件事 | 不要把"跌出前五 + 原因是供应链"塞进一句 |
| 全片句数 | 65–90 句（约 4 分钟）；少于 60 撑不满，多于 95 节奏散 |
| 场景切入 | `句子开始帧 - 6` |
| 动作密度 | 每 3–5 秒必须有一个视觉动作点，否则观众走神 |
| 单屏元素 | 3–6 件，观众自己决定看哪儿；超过 6 件就乱 |
| 翻页节奏 | 一页 5–12 秒；交叉淡化 16 帧 |
| 钩子 | 开头 7 句：现在的数字 → 反差 → "得把时间线拉出来看" |
| 收尾 | 最后 3–4 句往上抬，最后一句要短、能单独成立 |
| 大字位置 | 涉及数字的结论放画面中心偏上，字幕永远在底部 1/6 处 |

---

## 七、声音是怎么来的

全部程序化，零素材：

| 部分 | 做法 |
|---|---|
| 配乐 | 120 BPM，四小节和弦循环，按段落切换风格（轻扫弦 → 加鼓 → 小调紧张 → 收尾长音） |
| 音效 | 合成出来的"呼""叮""盖章""纸声""错误音"，短促无旋律 |
| 人声 | 神经网络 TTS（微软 edge-tts，晓晓音色，语速 +30%，音高 −3Hz） |
| 混音 | 人声出现时自动压低配乐（人声越响压得越狠），最终限幅到 −1 dBFS |

**两条铁律**：
1. **人声闪避**：不做这个，配乐一定盖住口播。
2. **音效克制**：只在换章和落结论时出声，数字从屏幕上方落到位的过程保持静音——数字落位配"叮"是廉价感的来源。

---

## 八、成片长什么样（交付形态）

| 项 | 规格 |
|---|---|
| 成片 | 1920×1080 / 30fps / H.264，3 分 50 秒 – 4 分 30 秒，约 40 MB |
| 封面 | **三种比例各一张**：16:9（1920×1080）、4:3（1440×1080）、3:4（1080×1440） |
| 文案 | 抖音标题 ≤ 25 字；描述**一句话 ≤ 32 字** + 数据日期 + 5–8 个标签 |
| 图文稿 | 口播文稿 + 逐条事实核查表 |

16:9 封面同时就是片子第 0 帧，所以它和成片开头是同一个组件。

## 九、据此写提示词：必须交代的 9 个要素

AI 拿到上面的原理后，写提示词时缺任何一项都会跑偏：

| # | 要素 | 说明 | 例子 |
|---|---|---|---|
| 1 | **选题** | 一家公司 / 一个行业 / 一个人的几十年 | 「阿里 26 年」 |
| 2 | **主线数值** | 贯穿全片的那条曲线画什么 | 市值（对数刻度，标「示意」） |
| 3 | **起落结构** | 几次崩、几次冲顶 | 3 次崩 + 2 次冲顶 |
| 4 | **骨架** | 场景切播 / 翻页账本 / 相机长卷 | 翻页账本 |
| 5 | **时长与句数** | 默认 4 分钟 / 65–90 句 | 4 分 15 秒 / 88 句 |
| 6 | **音色与语速** | 决定全片节奏 | 晓晓，+30%，−3Hz |
| 7 | **钩子反差** | 现在的数字 vs 一年前 | 1.95 万亿 vs 3.7 万亿 |
| 8 | **配色与字体** | 决定是"贴纸卡通"还是"暗金文献" | 近黑底 + 暖金 + 衬线 |
| 9 | **禁区** | 不画什么 | 不画真实 logo、不画真实肖像 |

### 提示词骨架（把方括号填掉即可）

```
做一期 [选题]，[骨架] 风格，[时长]，[句数] 句口播。
主线画 [数值]，[几次起落]。
开头钩子：[现在的数字] vs [一年前的数字]。
画面：[配色] + [字体]，[单屏元素数] 件，每 [动作密度] 一个动作点。
声音：[音色]，语速 [x%]，配乐 [情绪走向]，音效只在换章和落结论时出现。
所有画面元素在 [口播锚点] 上出现，不写死秒数。
交付：[成片规格] + 三比例封面 + 一句话标题与描述。
禁区：[不画什么]。
```

### 判断提示词写得好不好的三个标准

1. **可锚定**：每个画面动作都能对应到"第几句 / 哪个词"，而不是"大约第 30 秒"。
2. **可验证**：能抽出任意一帧检查（有没有叠、有没有出画、该撤的撤了没）。
3. **可重来**：改一句文案后，只需要重新配音，画面自动跟着走——如果做不到，说明锚点写死了。

---

## 十、一句话总结

**这套方法的本质是把视频降维成"函数 + 时间轴数据"。** 文案编译成每句的起止帧，起止帧编译成每个元素的出场时刻，最后把 7658 次函数求值的结果按 1/30 秒间隔排成一条时间轴。

所以它能做到剪辑软件做不到的三件事：任意一帧可回溯、全片风格改一个常数就切换、同一份口播能长成多个视觉版本。
